# Model Card: AI ประเมินความเสี่ยงราคาตั๋ว (FreezeFly)

## ทำอะไร

เมื่อลูกค้าจะตรึงราคาเที่ยวบินหนึ่ง เป็นระยะ 24 ชั่วโมง / 3 วัน / 7 วัน โมเดลตอบ 2 คำถาม:

1. **payout** (regression): เราน่าจะต้องจ่ายส่วนต่างราคาให้กี่ % ของราคาที่ล็อก ใช้ตั้งค่าธรรมเนียม
   `ค่าธรรมเนียม = ส่วนต่างที่คาด × 1.25 + 1.5%` จำกัดไว้ที่ 3–15%
2. **rise** (classification): โอกาสที่ราคาตอนสิทธิ์หมดอายุจะสูงกว่าตอนนี้ตั้งแต่ 3% ใช้แนะนำลูกค้า
   (≥60% แนะนำให้ตรึง, ≤30% บอกว่าราคานิ่ง ยังไม่ต้องตรึง)

## ข้อมูลนำเข้า

| ชื่อ | ความหมาย |
|---|---|
| `days_to_departure` | อีกกี่วันเครื่องออก |
| `horizon_days` | ระยะที่จะตรึง (1, 3, 7 วัน) |
| `route_volatility` | ความผันผวนปกติของเส้นทาง |
| `is_peak` | เครื่องออกช่วงเทศกาล (ปีใหม่, สงกรานต์) หรือไม่ |
| `price_ratio` | ราคาวันนี้สูง/ต่ำกว่าระดับปกติของเส้นทางกี่เท่า |

## ⚠️ ข้อจำกัดสำคัญ

**ข้อมูลฝึกมาจากตัวจำลองราคา (`app/pricing.py`) ไม่ใช่ราคาตลาดจริง** ผลการทดสอบด้านล่างจึงบอกว่าโมเดล
เรียนรู้รูปแบบของตัวจำลองได้ดีแค่ไหน และพิสูจน์ว่าระบบทำงานครบวงจร (สร้างข้อมูล → สอน → ใช้ตั้งราคาและแนะนำ)
แต่**ยังไม่ได้พิสูจน์ว่าทายราคาตลาดจริงได้แม่น** เมื่อมีข้อมูลราคาจริง ให้แทนที่ `build_dataset()` ในสคริปต์ฝึกแล้วรันใหม่

## ผลการทดสอบ

ฝึกด้วยเที่ยวบินก่อน 1 ก.ค. 2025 (156,560 ตัวอย่าง) ทดสอบกับเที่ยวบินหลังจากนั้นที่โมเดลไม่เคยเห็น (31,457 ตัวอย่าง)

| สิ่งที่วัด | AI | วิธีง่ายสำหรับเทียบ |
|---|---|---|
| ทายโอกาสราคาขึ้นถูก | **76.5%** (AUC 0.8324) | 58.5% (เดาว่าไม่ขึ้นเสมอ) |
| ความคลาดเคลื่อนของส่วนต่างที่ต้องจ่าย (MAE) | **2.4%** | 3.5% (ค่าเฉลี่ยตามระยะ) / 4.7% (เดาว่าไม่ขึ้น) |
| ค่าธรรมเนียมเฉลี่ย | **7.0%** | 7.2% (คงที่ 5/7/10%) |
| กรณีค่าธรรมเนียมไม่พอจ่ายส่วนต่าง | **21.9%** | 23.1% |
| ส่วนต่างเฉลี่ย (ค่าธรรมเนียม − ส่วนต่างที่จ่าย) | **2.2%** | 2.5% |

ตัวเลขสองแถวล่างคิดแบบระมัดระวังที่สุด: ลูกค้าทุกคนมาออกตั๋วตอนราคาสูงสุดในช่วงที่ตรึง

**สรุป:** AI ทายดีกว่าวิธีง่ายชัดเจน และทำให้ค่าธรรมเนียม**เป็นธรรมขึ้น** (ถูกลงเมื่อเสี่ยงน้อย แพงขึ้นเมื่อเสี่ยงมาก
ค่าเฉลี่ยต่ำกว่าแบบคงที่) แต่ส่วนต่างเฉลี่ยของบริษัทใกล้เคียงหรือต่ำกว่าแบบคงที่เล็กน้อย AI จึงไม่ได้ทำให้กำไรมากขึ้นโดยอัตโนมัติ

## การใช้งานบนเซิร์ฟเวอร์

โมเดลถูก export เป็น `app/price_model.json` และคำนวณด้วย Python ล้วนใน `app/price_ai.py`
เซิร์ฟเวอร์จึงไม่ต้องติดตั้ง scikit-learn ถ้าไฟล์โมเดลหาย ระบบใช้สูตรสำรองแทน (ดู `GET /ai/model-info`)

## สอนโมเดลใหม่

```bash
cd backend
pip install -r ml/requirements-ml.txt
python ml/train_price_model.py
```

รุ่นปัจจุบัน: `20261009-1637`
